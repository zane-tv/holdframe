# web-sims

Build a simulation or 3D video as one HTML page whose `render(t)` is a pure function of time, then capture it frame by frame.

Instruction text from [whaleyxbt/claude-motion](https://github.com/whaleyxbt/claude-motion), MIT License, copyright whaleyxbt. Unchanged. Capture scripts live in that repo's `sims/`, not here.
